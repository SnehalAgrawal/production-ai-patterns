# data/

| File | What it is | Written by |
|---|---|---|
| `variants.json` | Every run: split, chat model per step, settings overrides, whether it is labelled; v2's cap rule; the expected Ollama version and model IDs | by hand, before the freeze |
| `prices.json` | Published per-million-token rates checked on 2026-11-24 (OpenAI and Anthropic, Standard tier), which hosted model stands in for which local model, and an embedding rate | by hand, before the freeze |
| `FROZEN.json` | SHA-256 of the protocol, these two files, this demo's code, and every input and module used from 01 and 02 | `freeze.py`, once, before the first run |
| `runs.json` | Every run's record (`run.json`) and, per email: extraction, chunk ids, reply, 01-style label key, every model call with its tokens and `done_reason`, 01's draft check, the hash of the draft's inputs, query-embedding counts | `run.py export`, once, after the last run |
| `blind_labels.json` | Per-question labels for every distinct reply, from the blind worksheet | `labels.py import` |
| `post_hoc.json` | The raw output of every draft cut off at its limit (b0, v2, v3), where it stopped, and the agreement with #33's blind labels; written after the runs, outside the freeze (deviation D2) | `post_hoc.py` |
| `final_labels.json` | The same labels after a reviewer checked every one, with each change recorded (here a second Claude agent, not a person: the demo README's deviation D1) | `verify.py import` |

Everything in `runs/` (the per-run state files, the report and the per-case records) is git-ignored and regenerated by the commands in the demo's README. `runs.json` is the committed copy of what the runs produced.

The emails, documents, prompts, labels (questions and facts) and retrieval settings are 01's, used unchanged from [`01-reliable-llm-pipeline/data/`](../../01-reliable-llm-pipeline/data/).
